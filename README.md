# AIRS — エアーズ株式会社 コーポレートサイト

埼玉県日高市の空調設備・エアコン取り付け・資材販売「エアーズ株式会社」のWebサイト。

## 構成

静的HTML（Tailwind CSS CDN）。ビルド不要で、各HTMLをブラウザで直接開けます。

| ファイル | ページ |
|---|---|
| `index.html` | ホーム |
| `services.html` | サービス |
| `works.html` | 施工事例 |
| `company.html` | 会社概要 |
| `materials.html` | 資材販売 |
| `recruit.html` | 採用情報 |
| `contact.html` | お問い合わせ |

## デザイン

- テーマ: Pacific Breeze Industrial（西海岸サーフショップ風）
- 配色: Deep Navy `#0E3A5F` / Ocean Blue `#1FB2A5` / Coral `#FF7F50` / Sand Beige `#F4F1EA`
- フォント: Outfit（見出し）+ Noto Sans JP（本文）
